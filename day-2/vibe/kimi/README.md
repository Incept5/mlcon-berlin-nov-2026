# GDPR Article Explorer

A small, local-first web app for browsing GDPR articles by AI-generated summary.
The page banner is **Kimi K3.1**; article summaries are generated by the locally
installed **qwen3.5:4b** model through Ollama.

## Run

Keep Ollama running, then from this directory:

```bash
# Scrape Articles 20–25 and create gdpr.json (the smoke-test default)
python3 scrape_gdpr.py

# Serve the explorer locally
python3 server.py
```

Open **http://127.0.0.1:7001**.

The site itself is static. `server.py` uses only the Python standard library;
the scraper needs `requests` and `beautifulsoup4`.

## Expand to every article

```bash
python3 scrape_gdpr.py --start 1 --end 99
```

The new articles appear automatically—no HTML or JavaScript changes are needed.
The scraper writes after each successful article and reuses existing entries.
Use `--force` with a range to regenerate just those entries without discarding
the others.

Article text comes from <https://gdpr-info.eu/>. Summaries are generated locally
and are for orientation, not legal advice. The browser app makes no external
requests unless you choose to open the original-source link.
